# BPAC Bangla Phone Set (T11)

ASCII-safe (MFA-friendly) labels, with an IPA mapping. 30 consonants + 7 oral
vowels + 7 nasal vowels + 2 diphthongs = 46 phones.

## Vowels

| ASCII | IPA | Script source |
|---|---|---|
| a | a | আ, া (aa-kar) |
| O | ɔ | অ (independent, and the *inherent* vowel of a bare consonant) |
| o | o | ও, ো (o-kar) |
| i | i | ই/ঈ, ি/ী |
| u | u | উ/ঊ, ু/ূ |
| e | e | এ, ে |
| ri | ri | ঋ (vocalic r -- rare, Sanskrit loanwords) |

Diphthongs: `oi` (ঐ), `ou` (ঔ).

Nasal vowels (chandrabindu ঁ on the preceding vowel): `aN, ON, oN, iN, uN, eN`
(vocalic-r not nasalized in practice).

## Consonants

| Place | Voiceless unasp. | Voiceless asp. | Voiced unasp. | Voiced asp. | Nasal |
|---|---|---|---|---|---|
| Bilabial | p | ph | b | bh | m |
| Dental | t | th | d | dh | n |
| Retroflex | T | Th | D | Dh | -- |
| Velar | k | kh | g | gh | ng (from anusvara ং) |
| Palatal (affricate) | c | ch | j | jh | -- |

Other consonants: `s` (fricative -- শ/ষ/স all map to this ONE canonical
phone; see note below), `h` (হ), `l` (ল), `r` (র), `rr` (ড়/ঢ় flap, IPA ɽ),
`y` (য় and post-hasanta ্য), `w` (rare, conjunct glide).

## Deliberate simplifications / decisions (document in the paper)

1. **শ ষ স -> `s`, always.** Standard Bangla neutralizes these three
   orthographic sibilants to essentially one phoneme /s/ (or /ʃ/-ish,
   depending on dialect/register). The lexicon does **not** encode any
   regional variant here -- T16 (sibilant spectral-moment analysis) is what
   discovers the Sylhet /s/->/ʃ/ realization from the ACOUSTICS. Baking a
   regional pronunciation into the ground-truth lexicon would circularly
   assume the paper's own hypothesis.
2. **Visarga ঃ is dropped** (not realized as a phone). It is rare in the
   script and rarely pronounced in modern standard Bangla.
3. **এ is always `e`**, not distinguishing the /e/-/ɛ/ allophony that some
   analyses make context-dependent. A known simplification.
4. **Schwa deletion (অ-realization) is the single hardest rule.** This
   implementation applies the most common simplification used in
   computational Bangla G2P: the inherent vowel of a bare consonant (no
   following vowel sign, no following hasanta) is deleted **only when that
   consonant is word-final**; every other bare consonant keeps its inherent
   vowel `O`. This is correct for the large majority of common words but
   known to be wrong for some multi-syllable words with medial schwa
   deletion (e.g., certain verb conjugations) -- this is exactly what the
   manual review pass (top 500 by frequency + random 200 tail) exists to
   catch.
5. **্য (ya-phala)** after a consonant -> append `y`. **্র (ra-phala)** ->
   append `r`. Both are treated as simple glide/cluster insertions, not
   full gemination.

## Provenance

Generated by `bpac_phon/g2p.py` (rule-based; see module docstring). Cross-
checked against `epitran` (`ben-Beng`) where installable -- **not usable in
this environment**: epitran's `panphon` dependency uses Python 3.10+ syntax
(`str | None` type unions) and fails to import under this repo's Python 3.9.
`bnlp_toolkit` was also checked and has no G2P/phoneme module (tokenization,
NER, POS, embeddings only). The rule-based implementation is therefore
**authoritative**, as the spec anticipates for exactly this situation.
